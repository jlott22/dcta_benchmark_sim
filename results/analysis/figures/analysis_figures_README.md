# Final paper figures

This directory contains exactly the five authoritative 600-dpi PNG figures used by the paper:

- `primary_mission_performance_curves.png`
- `communication_performance_tradeoff.png`
- `prds_supplement.png`
- `grid_density_maximum_agent_steps_summary.png`
- `horizon_tuning.png`

Matching inspection PNGs and editable MATLAB `.fig` files are in `inspection/`. Every plotted value is stored in a dedicated CSV under `../tables/final_figure_sources/`.

All five figures are generated by `../generate_final_paper_figures_CLIPS_CV.m`, use the shared style in `../final_figure_style.m`, and are sized for the exact one- or two-column placement specified by the paper. Figure 4 uses common-six grid/density trial blocks; Figure 3 uses common-six nine-level communication trajectories.

Alternate layouts and superseded assets are intentionally excluded from the public tree and preserved only in the ignored root-level `archive_private/` directory.
